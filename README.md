# Online Food Delivery System

Frontend project for the review presentation.

## Technologies
- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive design using Flexbox, Grid and media queries

## Features
- Home page
- Food menu
- Search and category filters
- Add to cart
- Quantity controls
- Cart total calculation
- Checkout form
- Form validation
- Order confirmation
- Order history
- Basic order tracking UI
- Responsive mobile/tablet/desktop layout
- LocalStorage for cart and order history

## Current limitation
This is a frontend project. No real backend, database, authentication service, payment gateway or external API is connected yet.

## Future scope
Backend/API + database, real authentication, online payments, restaurant management, real-time tracking and deployment.
